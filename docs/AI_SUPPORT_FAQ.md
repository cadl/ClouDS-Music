## 客服回答原则

1. 产品名称统一写作 **ClouDS Music**。应明确它是第三方 3DS homebrew 测试版，
   与网易云音乐、Nintendo 均无隶属或背书关系。
2. 不承诺网易云私有接口长期可用，不把模拟器启动成功描述成真机兼容或已经实际
   出声。
3. 不提供绕过 VIP、地区、版权、下架或专辑购买限制的方法。
4. 不索取或让用户公开 `auth.bin`、`MUSIC_U`、Cookie、二维码 `codekey`、完整媒体
   URL、媒体鉴权参数或 `dspfirm.cdc`。
5. 优先给出用户可执行的操作；无法恢复、反复崩溃、疑似数据损坏或同类接口错误
   大量出现时，再按文末模板升级人工支持。

## 一、产品、设备与安装

### FAQ-001 ClouDS Music 是什么？

**标签：** 产品介绍、功能

**答：** ClouDS Music 是面向 Nintendo 3DS Homebrew Launcher 的第三方原生音乐
客户端。当前测试版支持公开新歌、每日推荐、搜索、二维码登录、我的歌单、标准
音质 MP3、同步歌词、封面、SD 卡缓存和 NDSP 播放。

### FAQ-002 这是网易云音乐官方客户端吗？

**标签：** 官方、免责声明

**答：** 不是。ClouDS Music 与网易云音乐、Nintendo 均无隶属或官方背书关系，
使用的是可能随时变化的非公开接口，因此部分在线功能未来可能暂时失效。

### FAQ-003 当前版本和状态是什么？

**标签：** 版本、测试版

**答：** 本问答库对应 `1.0.0`，发布日期为 2026-07-18。当前仍是可运行的测试版，
遇到问题时请先在设置页底部核对版本，并优先使用项目仓库公布的较新版本。

### FAQ-004 支持哪些设备？

**标签：** 3DS、2DS、机型

**答：** 项目目标是支持 Nintendo 3DS 系列 homebrew 环境，包括 Old 3DS/2DS 和
New 3DS 系列。裸眼 3D 歌词只在支持 3D 的机型上启用；2DS 系列会使用普通 2D
显示。不同机型、SD 卡和网络环境仍可能有性能差异。

### FAQ-005 原厂系统可以直接运行吗？

**标签：** Homebrew、CFW

**答：** 不能像官方商店软件一样直接运行。`.3dsx` 需要可用的 Homebrew Launcher
环境；`.cia` 版本需要已经安装 CFW，并通过 FBI 等工具安装。未配置 homebrew/CFW
的原厂系统不能直接安装 CIA。

### FAQ-006 3DSX 文件应该放在哪里？

**标签：** 安装路径、3DSX

**答：** 主程序的固定路径是：

```text
/3ds/ClouDS-Music/ClouDS-Music.3dsx
```

同时请确保 SD 卡可写，并保留应用创建数据目录的权限。

### FAQ-007 CIA 和 3DSX 的数据互通吗？

**标签：** CIA、3DSX、数据

**答：** 两者都把缓存、设置、播放列表和登录凭据保存在
`/3ds/ClouDS-Music`，因此使用同一张 SD 卡时会访问同一份应用数据。CIA 仍需要
DSP 固件，发行包不会内置该固件。

### FAQ-008 为什么发行包没有 DSP 固件？

**标签：** DSP、版权、音频

**答：** `dspfirm.cdc` 属于机主应从自己 3DS 提取的系统组件，项目不能下载、提交
或分发它。请使用对应的 homebrew 工具从自己的主机提取，不要从第三方索取或分享。

### FAQ-009 使用应用必须联网吗？

**标签：** 网络、离线

**答：** 首次获取推荐、搜索、登录、查看我的歌单和播放未缓存歌曲都需要联网。
断开 Wi-Fi 后可以继续播放播放列表中已经完整缓存且当前权限允许的歌曲。

### FAQ-010 对 SD 卡有什么要求？

**标签：** SD 卡、空间、写入

**答：** SD 卡必须可写。应用会保存设置、播放列表、登录凭据和媒体缓存；下载时还
会保留 64 MiB 安全余量。SD 卡只读、空间不足或文件系统异常都可能导致保存或下载
失败。

### FAQ-011 可以在 Azahar 模拟器中运行吗？

**标签：** Azahar、模拟器

**答：** 可以用于快速检查 UI、按键、网络、二维码、封面、歌词和缓存流程，但它
不能替代真机对 Old 3DS 内存、DSP 时序、SD 卡、Wi-Fi、合盖和耳机行为的验证。
模拟器窗口能启动也不代表音频链路已经实际出声；音频仍依赖正确的 DSP 环境。

### FAQ-012 怎样卸载并清除数据？

**标签：** 卸载、删除数据

**答：** 删除 3DSX 或卸载 CIA 只会移除程序，`/3ds/ClouDS-Music` 中的数据可能仍
保留。需要彻底清除时，请先退出应用并备份必要数据，再删除整个目录；这会同时删除
播放列表、设置、缓存和登录状态，无法从应用内恢复。

## 网站安装说明（可直接发布）

ClouDS Music 提供 CIA 和 3DSX 两种版本，请根据主机环境选择其中一种：

- **CIA 版：** 适合已经安装 CFW 和 FBI 的主机。安装后可以从 HOME Menu 启动。
- **3DSX 版：** 适合通过 Homebrew Launcher 启动，不会在 HOME Menu 中安装图标。

无论使用哪一种版本，SD 卡都必须可写，音频播放都需要机主从自己的 3DS 提取 DSP
固件。发行包和安装二维码不会包含 `dspfirm.cdc`。

### 方法一：使用 FBI 扫描二维码安装 CIA

1. 确认主机已经安装并可以正常打开 FBI，同时连接 Wi-Fi。
2. 在本网站打开 ClouDS Music 下载页面，找到 CIA 安装二维码。
3. 在 FBI 主菜单选择 `Remote Install`，再选择 `Scan QR Code`。不同 FBI 语言版本
   的菜单文字可能略有差异。
4. 将 3DS 摄像头对准网页上的二维码，识别后按 FBI 提示确认下载和安装。
5. 等待 FBI 明确显示安装成功。下载或安装期间不要关机、休眠或拔出 SD 卡。
6. 返回 HOME Menu，找到 `ClouDS Music` 图标并启动。

二维码应指向公开可访问的 **CIA 文件 HTTPS 直链**，而不是下载页面、二维码图片地址
或需要登录/Cookie 的临时链接。如果扫码识别成功但下载失败，可以改用下方的本地
CIA 安装方法。

### 方法二：通过 FBI 安装下载到 SD 卡的 CIA

1. 从本网站下载 `ClouDS-Music.cia`，并核对页面公布的版本、文件大小和 SHA-256
   校验值（如果提供）。
2. 将文件复制到 3DS 的 SD 卡。位置可以自行选择，例如：

   ```text
   /cias/ClouDS-Music.cia
   ```

3. 把 SD 卡装回主机并打开 FBI。
4. 在 FBI 中选择 `SD`，进入 CIA 所在目录并选中 `ClouDS-Music.cia`。
5. 选择 `Install CIA`；如果希望安装成功后同时删除安装包，可选择
   `Install and delete CIA`。菜单文字可能因 FBI 版本或语言不同而略有差异。
6. 等待安装成功后返回 HOME Menu，从 `ClouDS Music` 图标启动。

CIA 文件只是安装包。成功安装后可以删除 SD 卡上的 `.cia` 文件，但不要删除
`/3ds/ClouDS-Music` 数据目录，除非确实要同时清除设置、播放列表、缓存和登录状态。

### 方法三：通过 Homebrew Launcher 使用 3DSX

1. 从本网站下载 `ClouDS-Music.3dsx`。
2. 关闭主机并取出 SD 卡，或使用安全的 SD 卡文件管理方式。
3. 在 SD 卡根目录的 `3ds` 文件夹内创建 `ClouDS-Music` 目录，并把文件放到以下
   固定路径：

   ```text
   /3ds/ClouDS-Music/ClouDS-Music.3dsx
   ```

4. 将 SD 卡安全弹出并装回主机。
5. 打开 Homebrew Launcher，在应用列表中选择 ClouDS Music 启动。

如果 Homebrew Launcher 中没有显示应用，请确认目录层级和文件名完全一致，并确认
SD 卡能被主机正常识别。3DSX 不是 CIA，不要尝试在 FBI 中把 `.3dsx` 当作 CIA
安装。

### 首次启动

1. 确认 SD 卡不是只读并留有足够空间。应用会在 `/3ds/ClouDS-Music` 保存设置、
   播放列表、登录凭据和媒体缓存。
2. 需要使用推荐、搜索、登录、我的歌单或播放未缓存歌曲时，请先连接 Wi-Fi。
3. 如果提示 `NDSP unavailable`，请使用对应 homebrew 工具从自己的 3DS 提取 DSP
   固件，然后重启应用。不要下载或分享他人的 `dspfirm.cdc`。
4. 登录是可选的。公开新歌无需登录；每日推荐和我的歌单需要用网易云音乐手机 App
   扫码确认。

### 更新现有版本

1. 完全退出 ClouDS Music，建议先备份 SD 卡上的 `/3ds/ClouDS-Music` 数据目录。
2. CIA 用户可以用 FBI 安装网站提供的新 CIA；3DSX 用户直接替换固定路径中的
   `ClouDS-Music.3dsx`。
3. 不要为了更新而删除 `/3ds/ClouDS-Music` 数据目录，否则会同时失去设置、播放
   列表、缓存和登录状态。
4. 更新后在设置页底部核对版本号。若发布说明另有迁移要求，以对应版本的发布说明
   为准。

### 安装问题快速排查

- **FBI 无法识别二维码：** 放大二维码、提高屏幕亮度并保持画面平整；仍失败时直接
  下载 CIA 到 SD 卡安装。
- **二维码已识别但下载失败：** 检查 3DS Wi-Fi、日期/时间、SD 卡剩余空间，并确认
  网站二维码仍指向无需登录的 HTTPS CIA 直链。
- **FBI 提示 CIA 安装失败：** 重新下载文件并核对网站提供的文件大小和 SHA-256；
  不要继续使用下载不完整或校验不一致的安装包。
- **Homebrew Launcher 找不到 3DSX：** 检查文件是否准确位于
  `/3ds/ClouDS-Music/ClouDS-Music.3dsx`，并确认没有被浏览器额外添加 `.zip`、
  `.txt` 等扩展名。
- **应用能打开但没有声音：** 这通常不是安装包缺失，而是 NDSP/DSP 环境未就绪，
  请参见 FAQ-049。

### 网站发布建议

为减少 FBI 扫码安装和客服排查问题，下载页面建议同时显示：

- 当前版本、发布日期、CIA/3DSX 文件大小和各自的 SHA-256；
- CIA 安装二维码，以及同一个 CIA 文件的普通下载按钮；
- 3DSX 下载按钮和固定安装路径；
- “需要 CFW/FBI”与“需要 Homebrew Launcher”的醒目标识；
- 二维码对应的公开 HTTPS CIA 直链，不使用登录、Cookie 或短时效下载地址；
- 不包含、下载或分发 `dspfirm.cdc` 的说明。

每次发布后应在至少一台真机上重新测试二维码识别、CIA 完整下载、FBI 安装、HOME
Menu 启动和 3DSX 固定路径启动。二维码显示出来并不等于链接和安装流程已经通过。

## 二、界面与按键

### FAQ-013 如何切换上屏页面？

**标签：** L、R、Tab

**答：** 按 `L / R` 在 `NOW PLAYING`、`DISCOVER` 和 `SETTINGS` 三个 Tab 间切换。
切换 Tab 时焦点会重置到上屏内容。

### FAQ-014 为什么方向键控制不了上屏或下屏？

**标签：** 焦点、SELECT、播放列表

**答：** 应用同时有上屏内容和下屏播放列表两套焦点。按 `SELECT` 可以在两者之间
切换；也可以触摸下屏“播放列表”标题进入列表焦点。播放列表获得焦点后按 `B` 可
返回上屏。正在播放页没有可选的上屏项目，因此默认由播放列表持有焦点。

### FAQ-015 如何安全退出应用？

**标签：** START、退出

**答：** 按一次 `START` 后，在 3 秒内再按一次 `START` 确认退出。二次确认用于减少
误触导致的退出。

### FAQ-016 播放列表中怎样移动和翻页？

**标签：** 方向键、列表、翻页

**答：** 进入播放列表焦点后，`↑ / ↓` 逐首移动，`← / →` 按当前可见的 4 首整页
移动，到达首尾会停止。离线模式会自动跳过没有可用缓存的歌曲。

### FAQ-017 怎样删除播放列表中的歌曲？

**标签：** 删除、X、播放列表

**答：** 先按 `SELECT` 或触摸“播放列表”标题进入列表焦点，选中要删除的歌曲后按
`X`。删除的是本地播放队列项目，不会修改你的网易云歌单或收藏。

### FAQ-018 怎样播放、暂停、上一首和下一首？

**标签：** 播放控制、触摸、A

**答：** 可以直接触摸下屏的上一首、播放/暂停和下一首按钮。在播放列表中选中当前
歌曲时，也可以按 `A` 暂停或继续。实体音量由 3DS 的物理音量滑块控制。

### FAQ-019 怎样切换顺序、单曲循环和随机播放？

**标签：** 播放模式、SELECT、随机

**答：** 在正在播放页按 `SELECT`，或直接触摸下屏的播放模式按钮，即可在顺序播放、
单曲循环和随机播放之间切换。

### FAQ-020 为什么触摸歌曲后焦点框没有跟着变化？

**标签：** 触摸、焦点

**答：** 这是有意设计。触摸普通队列歌曲或播放按钮不会暗中改变上屏/下屏焦点。
需要用方向键控制播放列表时，请显式按 `SELECT` 或触摸“播放列表”标题。

## 三、推荐、搜索与歌单

### FAQ-021 公开新歌和每日推荐有什么区别？

**标签：** 推荐、新歌、每日推荐

**答：** “公开新歌”无需登录；“每日推荐”来自已登录账户的个性化推荐。进入推荐
入口后用 `← / →` 选择来源，列表每页 18 首，并分别记住各自的页码和选择位置。

### FAQ-022 怎样刷新推荐？

**标签：** 推荐、刷新、X

**答：** 在推荐歌曲列表中按 `X`，应用会刷新当前推荐来源的当前页。网络任务运行
期间请等待完成，或按 `B` 取消。

### FAQ-023 怎样搜索歌曲？

**标签：** 搜索、拼音

**答：** 在 `DISCOVER` 的 2×2 入口中选择“搜索”并按 `A` 打开，然后按 `A` 或 `X`
进入输入界面。可搜索歌曲、歌手或专辑关键词，按 `START` 提交搜索，结果页用
`← / →` 翻页。

### FAQ-024 拼音输入法怎样使用？

**标签：** IME、输入法、拼音

**答：** `X` 切换中文/英文，`Y` 切换字母与数字/符号键盘，`B` 删除字符；内容为空
时按 `B` 会取消。方向键或 Circle Pad 选择及翻页候选词，`A` 提交候选词，
`START` 开始搜索，`SELECT` 取消。候选词也可以直接触摸。

### FAQ-025 为什么只能输入英文，不能选择中文候选词？

**标签：** 拼音词典、英文回退

**答：** 如果界面提示“拼音词典不可用，已启用英文输入”，说明应用内置词典未能
加载。请确认使用的是完整、可信的发行文件并重新复制程序；若仍出现，请记录版本和
完整提示后升级人工支持。

### FAQ-026 搜索不到歌曲怎么办？

**标签：** 搜索无结果、网络

**答：** 先简化关键词，只保留歌名或歌手名，并确认 Wi-Fi 可用。仍无结果可能是
网易云没有返回匹配内容、歌曲受版权限制，或私有接口发生变化；可以稍后重试并提供
应用版本、关键词和界面错误，不要提供账号凭据。

### FAQ-027 怎样查看“我的歌单”？

**标签：** 我的歌单、登录

**答：** 在 `DISCOVER` 选择“我的歌单”并按 `A`。该功能需要登录，成功后会按需
加载你创建和收藏的音乐歌单；视频内容不会显示。歌单和歌曲列表每页显示 8 项，
用 `← / →` 翻页。

### FAQ-028 从歌单播放一首歌会离开歌单页吗？

**标签：** 歌单、播放

**答：** 不会。在歌单歌曲页选中一首歌并按 `A`，应用会把它加入本地播放列表并
尝试播放，但仍停留在当前歌单页面，方便继续浏览。

### FAQ-029 怎样把整个歌单加入播放列表？

**标签：** 全部加入、歌单、X

**答：** 在歌单歌曲页按 `X`，确认后应用会按页把整个歌单加入播放列表，并显示
页码、已处理数量和新增数量。过程中可按 `B` 取消；已经成功加入的歌曲会保留。

### FAQ-030 为什么整个歌单没有全部加入？

**标签：** 播放列表已满、批量加入

**答：** 本地播放列表最多 1000 首。批量加入不会为了腾出空间而删除原有歌曲，列表
满后会停止并报告仍有歌曲未加入；Wi-Fi 中断或手动取消也会提前停止。播放列表实际
超过 500 首后，旧版应用因容量不足无法加载，但不会删除数据；返回新版即可恢复。

### FAQ-031 播放列表满了，再加一首会怎样？

**标签：** 1000 首、替换

**答：** 单独加入第 1001 首时，应用会显示确认窗。按 `A` 确认后移除最早加入的
一首，再加入新歌曲；按 `B` 取消则不改变列表。批量加入整个歌单不会执行这种逐首
替换。

## 四、登录与账户

### FAQ-032 怎样登录网易云账户？

**标签：** 登录、二维码

**答：** 在 `DISCOVER` 选择“账户”，按 `A` 创建二维码，再用网易云音乐手机 App
扫码并在手机端确认。打开每日推荐或我的歌单时如果尚未登录，也会自动进入二维码
登录，成功后继续原操作。

### FAQ-033 二维码过期了怎么办？

**标签：** 二维码过期、重试

**答：** 返回账户页面重新按 `A` 生成二维码，再用手机 App 扫码并及时确认。若反复
过期，请检查 3DS 的网络和日期/时间，并稍后重试。

### FAQ-034 扫码后为什么还在等待？

**标签：** 手机确认、二维码

**答：** 扫码后还需要在网易云音乐手机 App 中确认登录。若手机已经确认但 3DS
没有更新，请确认 Wi-Fi 可用，等待一次状态检查；二维码过期后重新生成即可。

### FAQ-035 应用会保存网易云密码吗？

**标签：** 密码、隐私

**答：** 不会。应用采用手机扫码登录，不在 3DS 上保存账号密码；但会在
`/3ds/ClouDS-Music/auth.bin` 保存可复用的登录凭据，因此仍应把 SD 卡视为敏感
设备。

### FAQ-036 登录后重启应用还要重新扫码吗？

**标签：** 登录保持、会话

**答：** 通常不需要。应用会保存并在启动时验证会话。网络断开、DNS、连接或超时
错误不会主动清除凭据；只有服务端明确判定会话无效时，才会提示登录已过期并要求
重新扫码。

### FAQ-037 怎样退出登录？

**标签：** 退出登录、X

**答：** 在账户页按一次 `X`，然后在 3 秒内再次按 `X` 确认。退出会删除本地登录
凭据；账号留下的 VIP 完整缓存也不会再被当作当前可用离线资源。

### FAQ-038 网络断开时提示无法验证登录，会丢失账号吗？

**标签：** 离线、凭据保留

**答：** 一般不会。瞬态网络错误时应用会保留本地凭据，并显示暂时无法验证。网络
恢复后会重新探测和验证；不要因为这个提示手动分享或编辑 `auth.bin`。

### FAQ-039 能输入账号密码登录吗？

**标签：** 登录方式、密码

**答：** 当前不支持在 3DS 上输入账号密码，只支持使用网易云音乐手机 App 扫码并
确认登录。

## 五、播放、音频与歌词

### FAQ-040 选中歌曲后为什么没有立刻播放？

**标签：** 预缓冲、下载

**答：** 未缓存歌曲会先渐进写入 SD 卡。通常达到文件的 15% 后开始播放，但实际
门槛会限制在 256 KiB 到 1 MiB；服务端未给文件大小时使用 256 KiB。界面“准备
播放”的百分比表示距离启动门槛的进度，不是整首歌曲的下载百分比。

### FAQ-041 为什么播放时出现橙色缓冲动画？

**标签：** 缓冲、网络、SD 卡

**答：** 这表示已下载的数据暂时被播放消耗完，常见原因是网络变慢或 SD 卡写入
持续卡顿。应用会在积累至少 64 KiB 新数据后自动继续；若长时间不恢复，请检查
Wi-Fi、SD 卡剩余空间和写入状态后重试。

### FAQ-042 为什么下载时不能拖动进度条？

**标签：** Seek、进度条

**答：** 渐进下载期间还没有完整、可靠的 MP3 跳转索引，所以暂时禁用拖动。下载
完成并在后台建立索引后会自动恢复精确跳转；完整缓存首次打开时也可能短暂等待索引。

### FAQ-043 时间轴上的灰色和红色分别表示什么？

**标签：** 时间轴、下载进度

**答：** 低对比度灰色表示已经下载并刷入 SD 卡的范围，红色表示已经播放到的位置。
下载完成或使用完整缓存时，灰色会铺满时间轴；橙色用于加载或缓冲警告。

### FAQ-044 为什么没有同步歌词？

**标签：** 歌词、LRC

**答：** 可能是该歌曲没有可用的 LRC 同步歌词、歌词请求暂时失败，或当前离线且
此前没有缓存。歌词失败不会阻止音频继续播放；联网后可重新选择歌曲尝试，持续失败
时记录歌名、歌曲 ID（若界面可见）、版本和错误提示后升级人工支持。

### FAQ-045 为什么没有专辑封面但歌曲还能播放？

**标签：** 封面、非致命错误

**答：** 封面下载和解码是独立的非致命任务，失败时音频仍可播放。请检查网络和 SD
卡空间后重试；如果只有个别歌曲缺失，可能是远端没有可用封面或返回了不支持的图像。

### FAQ-046 支持哪些音质和格式？

**标签：** 标准音质、MP3、无损

**答：** 当前只请求标准音质 MP3，不支持 FLAC、AAC 或无损/高解析音质切换。

### FAQ-047 为什么 VIP 歌曲只能播放一小段？

**标签：** VIP、试听

**答：** 列表中的 `VIP` 是网易云返回的歌曲分类。当前账户没有完整播放权限时，
服务端可能只提供试听，状态栏会显示“VIP 试听播放中”。登录有相应权益的账户后，
应用会重新确认权限；它不会绕过会员或版权限制。

### FAQ-048 为什么某首歌显示不可播放？

**标签：** 地区限制、版权、下架

**答：** 常见原因包括地区限制、VIP/专辑购买权限、版权限制或歌曲已下架。应用只
使用服务端本次授予的资源，不会尝试绕过这些限制。可以先确认账号状态和网络；若
手机官方客户端也不可播放，则通常不是本应用故障。

### FAQ-049 为什么没有声音并提示 NDSP unavailable 或 D880A7FA？

**标签：** NDSP、DSP、D880A7FA、无声、Luma3DS、Rosalina

**答：** `D880A7FA` 表示系统没有在 SD 卡固定路径 `/3ds/dspfirm.cdc` 找到可用的
DSP 固件，也没有从 Homebrew Launcher 获得对应组件。这不是歌曲下载、缓存或 MP3
解码错误，不需要删除歌曲缓存或重新登录。不要把固件放在应用目录
`/3ds/ClouDS-Music`。应用在启动时检测到这个错误码会显示一次 Rosalina 操作引导；
按 `A` 或 `B` 可以关闭，但完成提取前仍无法播放音频。

Luma3DS v10.3 及以上版本可以直接从 Rosalina 菜单提取：

1. 回到 HOME Menu，使用默认组合键 `L + 十字键下 + SELECT` 打开 Rosalina。
2. 进入 `Miscellaneous options...`，选择 `Dump DSP firmware` 并按 `A`。
3. 确认界面显示固件已成功写入 `/3ds/dspfirm.cdc`。
4. 完全退出并重新启动 ClouDS Music。

`Dump DSP firmware` 首次随 Luma3DS v10.3 正式发布；v10.2.1 及更旧版本没有该
选项。用户可以在 Rosalina 主菜单左下角查看实际运行的 Luma3DS 版本。如果版本已经
达到 v10.3 但仍看不到，请确认进入的是 Rosalina 的 `Miscellaneous options...`，而
不是开机时按住 `SELECT` 打开的 Luma 配置界面，并尝试用方向键继续向下移动。SD 卡
中的 `boot.firm` 已更新但主机实际从 CTRNAND 启动旧版 Luma 时，也可能仍显示旧菜单。

提取失败时，请确认 HOME Menu 正在运行、SD 卡已插入且可写。旧版 Luma 可以更新到
官方新版本，或使用 DSP1 等对应 homebrew 工具从机主自己的 3DS 提取。不要下载、
分享或让客服代为提供 `dspfirm.cdc`。Luma3DS v10.3 的官方发布说明见
<https://github.com/LumaTeam/Luma3DS/releases/tag/v10.3>。若已从自己的主机正确
提取仍失败，请提供设备型号、完整错误码、应用版本、Luma3DS 版本和 3DSX/CIA 运行
方式，但不要提供固件文件本身。

### FAQ-050 为什么提示“音频已缓存但无法播放”？

**标签：** 已缓存、NDSP

**答：** 这通常表示下载和缓存已经成功，但本机 NDSP/DSP 音频环境没有就绪。修复
DSP 环境后可直接使用已经完成的缓存，不必因此删除歌曲或重新登录。

### FAQ-051 会自动播放下一首吗？

**标签：** 自动续播、下一首

**答：** 会。顺序和随机模式会按当前模式自动选择下一首；单曲循环会重复当前歌曲。
离线时会跳过播放列表中没有可用缓存的项目。

### FAQ-052 合盖后还能继续播放吗？

**标签：** 合盖、耳机、睡眠

**答：** 插入耳机且正在播放时，应用支持合盖继续播放、下载和自动续播。未插耳机
或当前已暂停时，主机会正常进入睡眠；播放中拔出耳机也会恢复正常睡眠策略。不同
机型仍建议真机确认。

### FAQ-053 裸眼 3D 歌词怎样工作？

**标签：** 3D、歌词

**答：** 在支持裸眼 3D 的机型上，提高 3D 滑块后，当前歌词行最靠前，距离当前行
越远的上下歌词会逐级后退；左侧封面、歌手和歌名按由远到近的三个浅层悬浮，面板
边框和状态文字留在屏幕平面。即使歌曲没有同步歌词，左侧播放卡片仍可显示该层次。
歌词就绪后，正在播放页的控制帮助会启用 `Y 沉浸`；
按 `Y` 会打开黑底全屏歌词，再按 `Y` 可循环切换四种原生 24px 点阵样式：只显示
当前句在中间放大、上下歌词沿弧线缩小滚动的“歌词滚轮”，在屏幕中央纵向翻入
新句的“中心翻转”，让当前句到点时立即满亮出现、保持到末段再快速消失的
“骤现渐隐”，
以及让多行歌词朝
消失点后退的“星际字幕”。星际字幕只显示当前句和过去歌词：当前句在最下方出现，
下一句开始时才新增一行；两句时间点之间，整组歌词会以线性速度持续向远处移动，
切句边界不会缓停。后两种
翻转和字幕样式同时使用远近缩放、
纵向透视压缩和受限的
左右眼视差；2D 模式仍保留相同的透视运动。顶部 `B 返回`、样式名称和 `Y 切换`
在进入或切换后显示 3 秒，再用约 1 秒淡出。下屏只显示纯黑画面，按 `B` 返回。
没有歌词时入口会置灰；把 3D 滑块降到零、退出沉浸页或
离开正在播放页会恢复普通 2D 显示。2DS 系列仍可使用沉浸页，但只显示 2D 歌词。

### FAQ-054 为什么显示“3D 不可用，已切换为 2D”？

**标签：** 3D 不可用、2D 回退

**答：** 可能是机型本身不支持 3D，或可选的右眼渲染资源分配失败。应用会继续以
2D 模式运行，这不应阻止普通播放。若支持 3D 的机型反复出现且伴随卡顿或崩溃，请
重启后记录机型、版本和错误提示并升级人工支持。

## 六、离线、缓存与存储

### FAQ-055 离线模式可以做什么？

**标签：** 离线模式、缓存

**答：** 离线时可以播放本地播放列表中已经完整缓存且当前权限允许的歌曲。推荐、
搜索、我的歌单、账户操作和加入未缓存新歌暂时不可用；上屏会显示断开的 Wi-Fi
图标。

### FAQ-056 为什么离线时有些歌曲变灰？

**标签：** 离线、灰色歌曲

**答：** 变灰表示没有可用的完整离线音频缓存。方向键、触摸、上一首、下一首、
随机和自动续播都会跳过这些项目；下载过程中的 `.part` 文件不会被当作可播放缓存。

### FAQ-057 VIP 缓存可以离线播放吗？

**标签：** VIP、离线权限

**答：** 试听缓存可以按试听资源离线播放。VIP 完整缓存只有在本地仍保留有效登录
凭据和相应权限时才可用；显式退出登录后，账号留下的 VIP 完整缓存不会继续播放。

### FAQ-058 应用会自动缓存下一首吗？

**标签：** 后台预取、下一首

**答：** 会。在当前歌曲的音频、封面和歌词都已完整缓存后，应用会沿播放列表向后
检查最多 16 首，并缓存第一首尚未完整缓存的歌曲。搜索、换歌和缓存管理等前台操作
会优先执行，后台预取仍受缓存上限约束。

### FAQ-059 缓存上限有哪些选项？

**标签：** 缓存设置、容量

**答：** 设置页可选 64、128、256、512 MB 或无上限，默认 256 MB。界面写作 MB，
内部按 MiB 计算；无上限只关闭按缓存总量自动淘汰，下载仍会保留 64 MiB 的 SD 卡
安全余量。设置会在重启后保留。降级到不认识无上限选项的旧版时，旧版会改用默认
上限，但不会删除已有媒体缓存。

### FAQ-060 降低缓存上限时为什么要再按一次 A？

**标签：** 缓存清理、二次确认

**答：** 如果新上限低于当前用量，第一次按 `A` 只显示确认提示；3 秒内再按一次
`A` 后，应用才会在后台优先清理较旧歌曲。当前正在播放歌曲会受到保护。

### FAQ-061 怎样清理全部缓存？

**标签：** 清理缓存、设置

**答：** 在设置页选择“清理缓存”，按 `A` 后根据提示再次按 `A` 确认。清理在后台
进行并保留当前播放歌曲的音频、封面和歌词；登录状态、设置和播放列表不属于媒体
缓存，不会被这个操作删除。

### FAQ-062 为什么清理后缓存仍不为零或仍超出上限？

**标签：** 受保护缓存、当前歌曲

**答：** 当前播放歌曲始终受保护，因此清理后可能仍有少量缓存；如果当前歌曲本身
超过新上限，界面会提示“已保留当前歌曲，缓存仍超出上限”。切换到其他歌曲后可
再次清理。

### FAQ-063 可以只删除一首歌的缓存吗？

**标签：** 单曲缓存、手动清理

**答：** 可以在应用完全退出后，删除 SD 卡上
`/3ds/ClouDS-Music/data/<song-id>/` 对应目录。该操作会同时删除该歌曲的音频、封面
和歌词缓存；不要删除当前正在播放歌曲的目录，也不要把删除播放列表项目误当作删除
缓存。

### FAQ-064 缓存损坏怎么办？

**标签：** 损坏缓存、重新下载

**答：** 应用会自动删除检测到的损坏 MP3 或歌词缓存，并在联网时重新获取。若同一
歌曲反复损坏，请先检查 SD 卡健康和剩余空间，再退出应用后删除该歌曲缓存目录并
重试。

### FAQ-065 各类数据存放在哪里？

**标签：** 文件路径、数据目录

**答：** 主要数据都在 `/3ds/ClouDS-Music`：

- `settings.bin`：语言和缓存上限；
- `playlist.bin`、`playlist.log`：本地播放列表及变更日志；
- `playlist-tracks.bin`：当前打开的网易云歌单歌曲 ID 索引；
- `auth.bin`：敏感登录凭据；
- `data/<song-id>/`：音频、封面和歌词缓存；
- `hardware.log`：仅在开启调试日志后写入的诊断记录。

不要向客服或公开渠道上传整个目录。

### FAQ-066 为什么提示 SD 卡空间不足？

**标签：** 空间不足、64 MiB

**答：** 应用下载时始终要求至少保留 64 MiB 安全余量；未选择“无上限”时还会受
用户设置的缓存上限约束。请先在设置中清理缓存或在电脑上释放 SD 卡空间，确认
SD 卡可写后再试；失败下载留下的 `.part` 文件会由应用清理。

### FAQ-067 为什么提示下载文件超过大小限制？

**标签：** 下载限制、封面、音频

**答：** 单个封面最大 2 MiB；未选择“无上限”时，单个音频不能超过当前缓存上限，
同时还必须满足 SD 卡安全余量。超限时应用会中止下载并删除临时 `.part` 文件。
可适当提高缓存上限；封面超过 2 MiB 的固定限制不能在设置中修改。

## 七、网络与常见错误

### FAQ-068 Wi-Fi 恢复后需要手动重启吗？

**标签：** 网络恢复、自动重试

**答：** 通常不需要。应用会自动探测 `https://music.163.com/` 是否恢复，失败后按
约 2、5、10、30 秒退避，之后每 30 秒重试；开盖或唤醒后也会立即探测一次。前台
请求可以随时优先执行，也可在界面提示下按 `A` 重试。

### FAQ-069 为什么提示证书校验失败？

**标签：** TLS、证书、日期时间

**答：** 应用强制 TLS 1.2、CA 和主机名校验，不会通过关闭验证来绕过错误。请先
校准主机日期/时间，再确认使用的是最新可信版本；仍失败可能是证书链或网络环境
异常，请保留错误文字并升级人工支持。

### FAQ-070 为什么网络请求失败后显示“已重试 1 次”？

**标签：** 自动重试、服务器错误

**答：** 对瞬态连接、TLS 或服务器错误，应用会自动重试一次。仍失败时请确认
Wi-Fi、日期/时间和网易云服务状态，稍后再试；连续快速重复操作通常不会改善结果。

### FAQ-071 公开推荐、搜索或登录突然都不能用了，怎么办？

**标签：** API 变化、在线功能

**答：** 先确认 Wi-Fi、日期/时间和应用版本。如果多个在线入口同时稳定失败，且
官方网络可用，可能是网易云私有接口发生变化。请提供版本、发生时间、受影响入口和
脱敏后的错误提示，等待项目更新；不要提供 Cookie、`auth.bin` 或完整请求地址。

### FAQ-072 “媒体下载失败”应该怎样处理？

**标签：** 下载失败、排查

**答：** 依次检查 Wi-Fi、SD 卡可写性、剩余空间和缓存上限，再重新选择歌曲。若
错误明确为地区、VIP 或版权限制，重试不会绕过权限；若明确为证书错误，先校准日期/
时间或更新应用。

### FAQ-073 为什么设置或播放列表无法保存？

**标签：** 保存失败、SD 卡

**答：** 常见原因是 SD 卡只读、空间不足、文件系统异常或目录不可写。请退出应用，
在电脑上备份 `/3ds/ClouDS-Music`，检查并修复 SD 卡，再确认目录可写。不要在应用
运行时直接修改 `.bin` 或 `.log` 文件。

### FAQ-074 为什么提示内存不足？

**标签：** 内存、Old 3DS

**答：** 请先退出并重新启动应用，避免同时执行不必要的后台操作，并确认使用最新
版本。若在 Old 3DS/2DS 上稳定复现，请记录设备型号、进入页面、操作步骤和开启
调试日志后的相关内存行，升级人工支持；模拟器结果不能代替同机型真机情况。

### FAQ-075 为什么“每日推荐不可用”但公开推荐还能显示？

**标签：** 每日推荐、降级

**答：** 每日推荐依赖有效登录和账户接口；它失败时应用可能回退显示无需登录的公开
新歌。请先检查账户页是否仍为已登录状态，必要时重新登录或稍后重试。

### FAQ-076 按 B 取消后是不是网络失败？

**标签：** 取消、B

**答：** 不是。`B` 会主动取消当前后台请求、下载或批量加入任务，界面可能显示
“任务已取消”或“请求已取消”。取消属于正常操作，未完成的媒体 `.part` 文件会被
清理；已经完成的批量加入项目会保留。

## 人工升级模板

AI 客服在以下情况应停止重复建议并升级人工支持：

- 同一错误在重启、确认网络/日期时间/SD 卡后仍能稳定复现；
- 支持 3D 的真机持续回退或出现渲染崩溃；
- 从用户自己的 3DS 正确提取 DSP 后仍然无法初始化 NDSP；
- 多名用户同时出现同一网易云响应/API 解析错误；
- 播放列表、设置或缓存持续损坏；
- 发现崩溃、内存持续下降、凭据泄漏或其他安全问题。

建议生成以下工单，不要要求用户上传整个数据目录：

```text
应用版本：
设备型号：
运行环境（3DSX/CIA/Azahar）：
系统/CFW 版本（如适用）：
是否真机复现：
网络状态：
SD 卡剩余空间/是否可写：
问题发生时间：
复现步骤：
界面完整错误：
相关 hardware.log 脱敏行：
已经尝试的操作：
```

提交前再次确认附件中不含 `auth.bin`、`MUSIC_U`、Cookie、二维码密钥、完整 URL、
媒体鉴权参数或 `dspfirm.cdc`。
